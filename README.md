# memo-project

React (Vite) で作成したシンプルなメモアプリです。

## 機能

- メモの追加(テキスト・カテゴリを指定)
- メモの編集・削除
- カテゴリによる絞り込み表示
- ブラウザを閉じても内容が残るローカルストレージへの自動保存

## セットアップ

アプリ本体は `memo-app/` ディレクトリにあります。まずそこへ移動します。

```bash
cd memo-app
npm install
```

## 使い方

### 1. 開発サーバーの起動

```bash
npm run dev
```

コマンド実行後に表示される URL(通常は http://localhost:5173)をブラウザで開きます。

### 2. メモを追加する

1. 画面上部のテキスト入力欄にメモの内容を入力します。
2. カテゴリ(仕事・個人・アイデア)をプルダウンから選択します。
3. 「追加」ボタンを押す、または入力欄で Enter キーを押すとメモが一覧に追加されます。

### 3. メモを編集する

1. 一覧の各メモにある「編集」ボタンを押します。
2. テキストを書き換えて「保存」ボタン(または Enter キー)で確定します。
3. 「キャンセル」ボタン(または Escape キー)で編集を取り消せます。

### 4. メモを削除する

一覧の各メモにある「削除」ボタンを押すと、そのメモが削除されます。

### 5. カテゴリで絞り込む

一覧上部のカテゴリボタン(すべて・仕事・個人・アイデア)を押すと、選択したカテゴリのメモだけが表示されます。

### 6. データの保存について

メモの追加・編集・削除を行うたびに、内容は自動的にブラウザのローカルストレージへ保存されます。ページを再読み込みしたり、ブラウザを閉じて再度開いたりしても、保存したメモはそのまま残ります。

## ビルド

本番用ビルドを作成する場合は以下を実行します(出力先は `memo-app/dist/`)。

```bash
npm run build
```

ビルド結果をローカルで確認する場合は以下を実行します。

```bash
npm run preview
```

## Lint

```bash
npm run lint
```
